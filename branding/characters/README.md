# Character cast (final, 9 characters)

Flat vector cartoon style. Every scene starts from one of these files, so the look stays consistent (the image tools cannot
reproduce a character from a text prompt, only from the source image). Names are working names; change them freely.
Made with Z-Image Turbo (free Hugging Face space for 01-05, Higgsfield `z_image` at 0.15 credits each for 06-09).

| File | Name | Role |
|---|---|---|
| 01-leo | Leo | the everyman newcomer, the viewer's stand-in (backpack, teal sweater) |
| 02-nico | Nico | the paperwork nerd who knows every form (curly hair, glasses, lanyard) |
| 03-marta | Marta | the veteran expat who has seen it all (yellow jacket, tote of papers) |
| 04-otto | Otto | the eternally lost newcomer, the main victim (beanie, two suitcases) |
| 05-buck | Buck | the clueless tourist (bearded, sandals with socks, passport) |
| 06-sr-carimbo | Sr. Carimbo | the deadpan clerk with the giant stamp ("carimbo" = stamp) |
| 07-sr-renda | Sr. Renda | the smug landlord ("renda" = rent), keys and a contract |
| 08-zoe | Zoe | the digital nomad, laptop and iced coffee |
| 09-dona-fernanda | Dona Fernanda | the formidable Portuguese grandmother neighbour |

Rules: never let the AI draw text or numbers on props; cover them in code. Check hands and props on every generated frame
(extra limbs and floating objects were the two faults seen so far).
